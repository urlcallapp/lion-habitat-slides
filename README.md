# האריה - מלך הסוואנה

מצגת HTML אינטראקטיבית בעברית (קובץ יחיד, בלי תלות ברשת): עולם סוואנה אחד שהשמיים בו משתנים לאורך המצגת, אריות מצוירים שעוקבים אחרי העכבר ושואגים בלחיצה, ואינטראקציות בכל שקף.

- ניווט: כפתורים, חיצים, רווח/Enter, החלקה במגע. כל לחיצה חושפת עובדה אחת, כדי שהמציג שולט בקצב.
- `N` הערות למציג, `F` מסך מלא, `R` שאגה, כפתור 🔊 מכבה צלילים (הצליל מסונתז, לא הקלטה, ומתנגן רק בלחיצה).
- `prefers-reduced-motion` מכבה אנימציות.
- עורכים ישירות את `index.html`: כל שקף הוא `<section class="slide">`, ועובדות הן אלמנטים עם הכיתה `frag`.
- המקורות בשקף האחרון. המפה בשקף 3 מצוירת ומשוערת.
